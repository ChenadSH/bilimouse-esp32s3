### 技术修正（重要）
- **BLE 鼠标无法读取主机光标位置**（只能发相对位移）。
  原 PRD 的"记录绝对坐标"方案在协议层不可行。
  改为 `main/app/pointer.c` 的**虚拟光标 + 增量路径**方案。
- **长按/超长按不能立即执行动作**。原实现 600ms 执行长按、1500ms 又执行超长按，
  一次按压触发两个动作（违反 PRD 约束，被单元测试抓出）。
  改为**松手时统一决策**，长按与超长按天然互斥。
  副作用（正向）：按住期间屏幕实时提示「松开 = xxx」，盲操体验更好。

## macOS 兼容 + I2C 修复（第二轮，提交 218de70 / 0325b25）

用户在 MacBook 上实测反馈「连上蓝牙但无输入、触摸不动、按钮太小」。定位出 6 个真 bug：

1. **广播包超限（致命）**：31 字节上限，字段顺序 flags→appearance→name→txpower→uuid128，
   "BiliMouse" 占位后 128 位 UUID 被截断为 0 长度 → macOS 不识别为 HID 设备。
   修复：改用 16 位 HID 服务 UUID 0x1812（BLE HID 规范标准做法），广播包 25/31 字节。
2. **缺 LE Secure Connections**：ESP_LE_AUTH_BOND 不含 SC 位，Apple 强制要求 SC。
   改为 ESP_LE_AUTH_REQ_SC_BOND。
3. **CCCD 订阅无跟踪**：官方示例 ESP_GATTS_CONF_EVT 为空。加订阅状态回调，
   hid_device_is_ready() = 已连接+已加密+主机已订阅。
4. **UI 重构**：遥控模式屏幕直显大按钮（100x64 主行 + 74x50 次行），屏幕任意空白处拖动=移动指针（原仅鼠标模式可拖）。
5. **I2C 总线重复创建（致命）**：三个驱动各调 i2c_new_master_bus()，后两个拿到
   ESP_ERR_INVALID_STATE 且句柄为野值 → 触摸 100 行/秒错误日志风暴饿死蓝牙任务。
   新增 bsp/bsp_i2c.c 统一总线管理层。
6. **bsp_touch_init 从未被调用**：app_main 漏了初始化调用，触摸任务裸奔。已补上。

教训：IDF v6 i2c_new_master_bus 失败时不写输出句柄；复用总线需自建管理层。
